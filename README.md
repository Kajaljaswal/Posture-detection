# Posture-detection

Posture Detection System: Developed an advanced deep learning-based posture detection system aimed at improving ergonomic safety in agricultural settings.
# dataset
 The system uses a customized ICAR dataset, which includes curated images from video data frames, categorized into - bending, squatting, standing and other postures for better classification.
 
# models Used 
The system uses VGG16, CNN-LSTM, and Vision Transformer models to accurately classify agricultural postures based on this customized ICAR dataset.

# use case
Designed for real-time analysis, the system is  further aimed to optimized for deployment on edge devices like Raspberry Pi, enabling on-site posture detection with low latency. This solution can be used to assess ergonomic risks by measuring RULA and REBA scores, providing valuable insights to improve worker safety and productivity in agriculture.
